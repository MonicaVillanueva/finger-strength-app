# Privacy & Offline Policy

- Default: fully offline. No analytics or network calls unless user explicitly opts in.
- Local data only: profiles, workouts, sessions stored on-device.
- Export/Import: user-initiated file export (CSV/JSON) to external storage or share sheet.
- Permissions: only request BLE and storage permissions when needed for features.
- Optional encryption: offer password-protected export or encrypted local DB as an opt-in feature.
- Guest mode: guest sessions are isolated and clearly marked; no profile changes unless user confirms import.
