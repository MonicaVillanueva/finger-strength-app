# Roadmap (phases)

MVP (Phase 1):
- BLE live data streaming from WH-C06 (manual mapping or known GATT)
- Profile CRUD + weight/max storage
- Workout create/edit/run with range checks and audio cues
- Guest live-data mode and CSV export
- Offline-first behavior and local persistence

Phase 2:
- Automatic rep detection, progression suggestions
- UI polish, accessibility improvements, localization
- Additional device support and easier device-probing UX

Phase 3:
- Optional cloud backup (opt-in), community workouts sharing, analytics (opt-in)

Notes: scope is intentionally conservative to keep the app lightweight.
