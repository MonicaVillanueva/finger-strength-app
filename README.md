# FingerStrenght

A project built using Expo and React Native to explore and learn the ecosystem. This is not a production-ready app, but a sandbox to understand mobile development concepts, tools, and best practices.

The demo app is just a simple example to measure and track finger strength workouts for climbing.

Initial learning following the [React Native Full Course for Beginners | Complete All-in-One Tutorial | 4 Hours](https://www.youtube.com/watch?v=WDunoPNBxKA) tutorial

## 1. Tech stack
* React Native
* Expo
